# Oak Meadow

Open `Assets/Scenes/terrain/oak_meadow.scene` and press Play. WASD moves, mouse looks, Shift sprints.

The forest stress scene uses **2,048 oaks** across a **328 x 328 m** area, a painted three-layer ground, a winding footpath and seventeen oak varieties. Irregular canopy clusters include 569 close companions at roughly 2-3 m spacing; the narrow footpath remains clear. Trees select shared resident geometry as the camera moves: LOD0 within 20 m, LOD1 to 60 m, and an authored 28-triangle impostor beyond. The four large-oak middle bands use coverage-pruned 3D Canopy prefabs; source LOD1 meshes remain available. Complementary spatial dithering blends each boundary over a one-metre interval. Placements reference the base variety, rather than a starting-camera LOD. Trees are compact shared-prefab placements in the terrain child `Oak forest` (`TerrainObjectLayer`), referencing editable assets under `Assets/Prefabs/Woodland/Oaks`. Prefab parts share source geometry and materials instead of expanding a full object hierarchy for every tree. Oak prefabs currently contain no collider or rigid body. Add a primitive collider to the LOD0/base prefab to apply it to every placement of that oak variety, including its configured visual LOD and impostor variants; saved prefab edits are polled once per second. The terrain Objects brush stores prefab references in these layers.

One continuous 60x60 terrain grid covers the grove and horizon without overlapping surfaces. Grass from `grass_flat_test.scene` is authored across the full 360 m terrain and streamed to a 36 m view distance using its existing LODs and wind settings. Grass roots and normals follow the actual terrain triangles, leaving the painted footpath clear. Grass placement data lives in `Assets/Prefabs/Woodland/OakMeadowGrass.prefab`, attached directly beneath the terrain. There is no shrub-prefab layer in this scene.

`Mesh.foliageWindStrength` enables the shared root-pinned wind field for authored meshes. The oak meadow scene intentionally keeps tree trunks and canopies at zero wind so they remain static and do not trigger shadow-map churn from shader-driven vertex motion. The same vertex path drives color and shadows, with bounds padding for wind. Bark and canopies keep source PBR shading. The scene enables generic distance texture LOD: full quality within 12 m, smoothly reaching +4 mip bias at 48 m, with normal/material detail and reflections fading over that interval. Adjust Texture LOD in Scene Properties or enable a material override. Bark is one-sided; leaf cards remain two-sided to preserve canopy coverage. Terrain renders only its upward-facing surface.

Rebuild only tree placements with `python Scripts/Assets/build_oak_meadow.py --forest-only`, preserving the current terrain, grass and scene settings. Regenerate all assets with `python Scripts/Assets/build_oak_meadow.py --prepare-only`, then `python Scripts/Assets/build_oak_meadow.py` (numpy/scipy and a built Debug Editor required). Existing imported packs are reused. Imports use the native glTF importer; generated intermediates live under `.local/woodland-import`. See ATTRIBUTION.md for CC-BY-4.0 credits.
