Follow these steps to turn off the jacket for MMD model:
1. Open MMD (MikuMikuDance) and load .pmx model.
2. In Facial manipulation (green tab) click on roll up "Other" tab.
3. Click on 7th facial tab with name "Jacket off".
4. Roll slider to the right (to value 1.0).
5. Click Register and jacket is turned off.

--Two PMX files, one with toon tex and the other flat painted textures only. Use the one you like!!

--VRChat File is not optimized but setup with all basic functionalities as well as toggles for Jacket, headphones & claws.

--A separate fbx file is provided in case you want more optimized version, you will be able to do it yourself by using this file.
