# Engine TODO

## Generalize terrain and foliage systems for arbitrary objects


- [ ] **Generalize cell streaming and preparation budgets.** Separate the spatial cell/layer lifecycle from terrain generation so ordinary object clusters and repeated prefab groups can be prepared, uploaded, streamed, and unloaded through the same budgeted path. Keep terrain as one provider; allow scene-authored cells or generic object layers to supply bounds and source data. Track cold/warm preparation, upload bytes, memory residency, and edit/unload safety for each provider. **Engine connection:** use `TerrainManager`'s cell lifecycle and `TerrainObjectLayer::PreparePrefabInstances` as migration inputs, while keeping rendering-independent preparation contracts. **Reference connection:** [Unreal Level Instancing](https://dev.epicgames.com/documentation/en-us/unreal-engine/level-instancing-in-unreal-engine) demonstrates repeated object arrangements, while noting that streaming policy is supplied by the owning world system rather than inherent to the instance itself.

- [ ] **Migrate terrain foliage incrementally and validate other object classes.** Keep a compatibility adapter so existing terrain scenes and serialized placements continue to load. Move one representative foliage layer onto the generic path, then verify ordinary repeated static props, non-instanced LOD meshes, multi-mesh prefabs, shadow casters, and dynamic/deformed exclusions. Compare appearance, selection/editing, stream-in/out, memory, draw counts, selected LODs, and CPU/GPU timings against current captures before removing terrain-only duplication. **Reference connection:** [Unity LOD Group's renderer-set model](https://docs.unity3d.com/6000.0/Documentation/Manual/class-LODGroup.html) and [Unreal's general static-mesh instancing model](https://dev.epicgames.com/documentation/en-us/unreal-engine/instanced-static-mesh-component-in-unreal-engine?application_version=5.8) show that LOD and instancing should apply across object classes; the [Oak LOD study](../.local/performance-logs/oak-lod-study-20261111/summary.md) remains the foliage-specific regression baseline.
