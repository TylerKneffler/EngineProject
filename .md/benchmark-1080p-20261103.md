# Standard 1080p benchmarks - 2026-11-03

All benchmark render targets are fixed at **1920 x 1080** (2,073,600 pixels). Editor auto-profile runs use a locked 16:9 Game view; panel and window resizing cannot shrink the target. Arbitrary benchmark width/height overrides have been removed or restricted to 1080p. Normal editor sizing remains unchanged. The terrain/foliage runners reject traces with any measured frame at another resolution.

Built and ran the current Debug DX11 executables sequentially. All six runs exited successfully; every measured frame was checked for the correct resolution.

| Case | Measured frames | Average FPS | Mean interval (ms) | P95 interval (ms) | P99 interval (ms) |
| --- | ---: | ---: | ---: | ---: | ---: |
| Editor grass, serial | 180 | 60.07 | 16.647 | 18.084 | 21.535 |
| Editor grass, parallel | 180 | 64.62 | 15.474 | 16.462 | 16.742 |
| Terrain moving route / terrain-1920x1080 | 240 | 122.54 | 8.161 | 19.003 | 93.234 |
| Foliage moving route / foliage-off | 240 | 290.34 | 3.444 | 6.108 | 19.218 |
| Foliage moving route / foliage-on | 240 | 66.42 | 15.056 | 19.343 | 28.124 |
| Foliage moving route / foliage-shadows-off | 240 | 71.42 | 14.001 | 17.684 | 25.116 |

FPS is 1000 divided by mean measured frame interval. Percentiles describe frame intervals, so lower is better.

The editor parallel run improved average FPS by 7.6% and reduced mean interval by 7.0%. Both editor runs used a stationary camera, 60 warmup frames, 180 measured frames, and 3,422 grass instances throughout. Each had zero dropped or failed profiler records. Render preparation averaged 9.879 ms serial and 10.823 ms parallel; parallel simulation averaged 1.425 ms with 1.090 ms overlapping submission. Preparation remains the largest measured CPU scope.

The helper runs use a moving route and omit editor UI and physics. Their results should be compared within that scope, separately from the editor runs. Terrain streaming still shows a large P99 interval. These are single Debug captures, not repeated Release measurements; GPU stages overlap CPU timing and cannot be added to frame intervals. The editor evaluator does not record the full matched-route identity fields, so no GPU-stage delta claim is made.

The editor layout and asset index were backed up before running and restored byte-for-byte afterwards.
